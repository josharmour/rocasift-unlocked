# Contributing

Open an issue with a reproducible observation, proposed export workflow, or link to public research. Label observations and hypotheses separately.

Include the date, firmware version when available, expected behavior, actual behavior, and reproduction steps. For stalled jobs, record power-light behavior, roller-path lights, whether the rollers move, and the exact portal error. Redact account/device identifiers from screenshots.

Keep changes focused. Use imperative commit subjects such as `docs: describe image export pagination`. Explain what evidence supports the change and what remains untested.

Do not upload credentials, cookies, private card collections, raw network captures, proprietary firmware, or vendor PDFs. Link to official documentation instead. Preserve original evidence locally and submit a redacted summary.

There is no build or test suite yet. Check Markdown links and verify claims against their cited evidence. New automation should document installation, authentication, rate limits, recovery behavior, and tests for incomplete downloads.
