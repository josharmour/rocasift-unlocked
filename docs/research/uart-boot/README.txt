ROCA UART ANNOTATED REPORT

Open roca-uart-annotated.html in a browser. It is self-contained and makes no network requests.

coverage.json inventories original capture byte sizes, physical line counts and SHA-256 digests.
line-map.jsonl maps every original physical line (and each reconstructed UART line) to an entry ID.
annotations.json contains the full redacted original text and interpretation for each display entry.

The HTML collapses only adjacent identical redacted lines with identical annotations; each individual line remains in the index.
Raw timestamp+hex UART records link to reassembled complete-message annotations.
Original private captures are not included. No device actions or configuration changes were performed.
